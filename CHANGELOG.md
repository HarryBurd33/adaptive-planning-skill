# Changelog

## 0.3.0 — 2026-10-30

- Add read-only trial reporting with explicit baseline/review metadata, local observation dates, unknown tracking, and raw duration samples without guessed totals or causes.
- Add stable-UID UTC iCalendar and escaped Markdown/Obsidian exports, excluding completed/ended work and preserving in-progress starts.
- Add exclusive/private file output with identical retry support, changed-file and source-alias protection; no automatic imports or external operations.
- Add independent pinned iCalendar-parser checks in CI, synthetic trial example, and28 regressions (98 total, all70 prior tests retained).
- Preserve version1/2 state compatibility. No trial starts, reminders, account connections, personal data migration, or cloud sync merely by installing.

## 0.2.0 — 2026-10-30

- Reject circular model-week overlaps and incomplete known prerequisite allocations, including transitive blocked/unknown readiness. Generic protection layers may overlap and are unioned; actual activity collisions still fail.
- Add opt-in version-2 availability, fractional buffer, and anchored sleep-exception constraints; preserve version-1 readability and reject unsafe downgrades.
- Add explicit `--as-of` elapsed-history preservation and future-effort accounting, with stable retry semantics.
- Add a dependency-free capacity/view utility with unknown-versus-zero handling, deadline/minimum-session bounds, one buffer charge, partial-period deferral, and day/week/month minute conservation.
- Add independent full-schema CI validation using pinned development-only tools, concise continuity guidance/template, and separate-context baseline/candidate evidence.
- All 32 original tests remain; 38 new tests bring the deterministic suite to 70. Keep prior code/state backups; installation does not migrate personal state.

The optional helper is not a full optimizer, calendar connector, reminder scheduler or automatic cross-device memory. Real-user trials and optional integrations remain future work.
